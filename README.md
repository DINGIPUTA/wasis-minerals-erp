# Stone Trade Management System — Enhanced

Included:
- Multi-user login and roles
- Ship/import records
- Ship-specific extra costs (freight, unloading, port, etc.) and effective cost/ton
- Stock
- Customers
- Sales/delivery
- Customer ledger with running balance
- Payments
- Trucks
- Expenses
- Reports
- CSV export for sales, stock and customers

Default admin: admin / admin123

For 10–15 simultaneous office users, deploy on a server/PC accessible over LAN/VPN. For production, PostgreSQL + HTTPS + automated backup is recommended.
